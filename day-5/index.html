Day 5 · Fifteen minutes

Own it.

CLI, agents, themes of your own, and the safety net under the floor.

Command center

Type omarchy. Then tab.

omarchy omarchy theme set inkblade omarchy pkg add cowsay omarchy update

Every group takes --help. Agents can drive this. That's the point.

AI, first-class

Pick an agent. Don't download until you run it.

Default agentSuper+Shift+Ctrl+A
Herdr workspaceSuper+Ctrl+Return

Stubs in ~/.local/bin. a for the default, c / cx / cy for OpenCode, Claude, Codex.

A theme of your own

Aether, or a folder.

  • Copy a theme from /usr/share/omarchy/themes → ~/.config/omarchy/themes
  • Edit colors.toml — that's the palette everything is generated from
  • Or open Aether from the apps menu and paint

Small, legal tweaks

  • Gaps and rounding: looknfeel.lua
  • Bar position: drag it, or omarchy bar position bottom
  • Hide the bar: Super+Shift+Space

Common tweaks live in the manual. Updates may park your edit in a .bak if they have to restore a file.

When it breaks

#omarchy-help, then the levers.

  • omarchy debug — share that, not a vibe
  • Boot a snapshot from Limine
  • omarchy reinstall configs if the files are the mess

Snapshots

Updates snapshot for you. /root rolls back. /home does not.

omarchy-snapshot create when you want your own. Restore from Limine, or omarchy-snapshot restore once you're inside.

The bargain

Encryption is the lock. Auto-login is the door.

  • LUKS at boot is the security model
  • That's why a Bluetooth keyboard can't unlock the disk
  • Firewall on; incoming closed except SSH and LocalSend

Elsewhere

Dual-boot. Intel Macs. Other people's machines.

Free-space install beside Windows — BitLocker off first. Intel Macs are supported. M-series and odd hardware live in Discord #omarchy-on-other.

More looks

omarchy.org/themes

Install from a git URL. Ship your own as omarchy-[name]-theme. The extra list takes a pull request.
