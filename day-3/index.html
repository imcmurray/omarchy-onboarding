Day 3 · Fifteen minutes

Work.

The bar, the clipboard, the capture keys, the apps you live in.

The strip

The top bar is the shell.

Quickshell draws the bar, the menu, notifications, OSD, and the lock screen. One process. That's why it themes as one piece.

Panels, not tooltips

AudioSuper+Ctrl+A
NetworkSuper+Ctrl+W
BluetoothSuper+Ctrl+B
Display / PowerSuper+Ctrl+D P

Arrows, Return, Tab, Esc. You never have to aim at a 16-pixel glyph.

Clipboard

One copy. Even in the terminal.

Copy / cut / pasteSuper+C X V
HistorySuper+Ctrl+V

No Ctrl+Shift+C folklore. Super+X is cut, except in the terminal.

Capture

Print Screen is a camera.

ScreenshotPrint Screen
RecordAlt+Print Screen
No PrtScn key?Super+Ctrl+C

Shot lands on disk and on the clipboard. Click the notification to annotate.

Notifications & time

Dismiss / allSuper+, Super+Shift+,
HistorySuper+Shift+Alt+,
ReminderSuper+Ctrl+R

Invoke the last notification with Super+Alt+comma. CLI: omarchy reminder 7 'Tea ready'.

Launchers

Menu for discovery. Hotkeys for home.

EverythingSuper+Space
Apps onlySuper+Alt+Space
CheatsheetSuper+K

The menu is not how you should launch the terminal on a Tuesday.

Where work happens

Terminal

Super+Return. Foot by default. Ghostty / Kitty via Install → Terminal.

Neovim

Super+Shift+N, or type n in a directory. LazyVim. Leader is Space.

Browser

Super+Shift+Return. Chromium, themed. Private: Super+Shift+Alt+B.

OBS

From the menu. This is how the Omarchy screencasts — and this series — get made.

Also on the machine

  • LibreOffice, Kdenlive, Obsidian, Signal
  • LocalSend as AirDrop — Super+Ctrl+S
  • Install → Package or omarchy pkg add

Grab more than pixels

Colour, text, a voice.

  • Super + Print Screen — eyedropper
  • Super + Ctrl + Print Screen — OCR to clipboard
  • Dictation is optional: Install → AI → Dictation

Recap

Work is a handful of keys.

Copy anywhereSuper+C V
HistorySuper+Ctrl+V
Shot / recPrint Screen Alt+Print Screen

Homework

Capture something real.

  1. Take a screenshot. Paste it with Super+V.
  2. Record thirty seconds. Stop with the same hotkey.
  3. Copy from the terminal with Super+C. Believe it.
