**You say:**

If you're still installing: ISO from omarchy dot org. Write it to a USB. Boot it. I am not doing an install episode. Three gotchas, because these three eat evenings.

One. Secure Boot and TPM off. If the stick won't boot, that's usually it. Firmware, not Omarchy being mysterious.

Two. Use a wired keyboard, or a two-point-four gigahertz dongle. Full-disk encryption — LUKS — will not take a password from Bluetooth at boot. Same as a BIOS. Your fancy wireless board is a brick until the disk unlocks. Plug in a cable, type the passphrase, then go back to the nice keyboard.

Three. Dual-boot is a free-space install in Quattro. Shrink Windows, leave unallocated space, let Omarchy take the gap. Turn BitLocker off first, or Windows will come back and refuse to understand its own drive.

That's the install speech. Discord is next.
