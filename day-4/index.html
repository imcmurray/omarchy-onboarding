Day 4 · Fifteen minutes

Make it yours.

Themes first. Then the files that are actually yours.

Twenty-two shipped

Pick a world in one chord.

Theme pickerSuper+Ctrl+Shift+Space
BackgroundsSuper+Ctrl+Space

Also Style → Theme in the menu. Desktop, terminal, Neovim, Chromium, the whole shell.

Worked example

Install Inkblade.

omarchy theme install https://github.com/imcmurray/omarchy-inkblade-theme

Or Install → Style → Theme and paste that URL. Then pick it from the theme list.

The rule

~/.config is yours. /usr/share/omarchy is the package.

Overwrite in ~/.config. Never edit the share tree — the next update will just put it back.

Setup menu

Don't hunt for files. Ask Setup.

  • Setup → Monitors, Keybindings, Input
  • Setup → Config → the file you mean
  • Quit the editor (:wq) and Omarchy restarts what must restart

Hyprland

hyprland.lua loads your overrides.

  • ~/.config/hypr/hyprland.lua — the main file
  • bindings.lua — keys you add or unbind
  • monitors.lua — displays, scale, position
  • looknfeel.lua — gaps, borders, layout default

The shell

shell.json is the bar — once you touch it.

~/.config/omarchy/shell.json becomes canonical the moment you drag a widget. New defaults won't appear until you omarchy bar defaults.

Updates

One command. Snapshot first.

  • Update → Omarchy — or the badge by the clock
  • Don't freelance pacman -Syu
  • Broken? Reboot and pick the snapshot in Limine

If you make a mess

  • Update → Config resets one file
  • omarchy reinstall configs resets all of them
  • omarchy reinstall is the big red lever

Type

The font is a menu item.

Style → Font. JetBrainsMono Nerd Font out of the box. Extra programming fonts under Install → Style → Font.

bindings.lua

Unbind, then bind.

hl.unbind("SUPER + SHIFT + O") o.bind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")

Setup → Keybindings opens the file. :wq restarts what must restart.

Recap

Style is a hotkey. Config is a folder.

ThemeSuper+Ctrl+Shift+Space
BackgroundSuper+Ctrl+Space

Edit ~/.config. Leave /usr/share/omarchy alone.

Homework

  1. Switch theme — Inkblade, or anything that makes you stay.
  2. Change one official config via Setup. Save. Come back.
